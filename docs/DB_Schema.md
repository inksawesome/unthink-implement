# Database Schema

The database uses PostgreSQL and is managed by Prisma ORM.

## Enums
- `Role`: `PATIENT`, `DOCTOR`, `ADMIN`
- `AppointmentStatus`: `PENDING`, `BOOKED`, `COMPLETED`, `CANCELLED`
- `Frequency`: `DAILY`, `TWICE_DAILY`, `WEEKLY`, `AS_NEEDED`

## Models

### User
Stores universal account information and authentication credentials.
- `id` (UUID, Primary Key)
- `email` (String, Unique)
- `passwordHash` (String)
- `name` (String)
- `role` (Role Enum)
- *Timestamps*: `createdAt`, `updatedAt`

### Doctor
Extends the User model with doctor-specific information and scheduling configurations.
- `id` (UUID, Primary Key)
- `userId` (String, Foreign Key to User, Unique)
- `specialization` (String)
- `workingHours` (JSON) - e.g., `{"mon": ["09:00-17:00"]}`
- `slotDurationMins` (Int, Default 30)
- `googleRefreshToken` (String, Nullable) - Stored securely for Calendar API.
- *Timestamps*: `createdAt`, `updatedAt`

### Leave
Represents days off for doctors. Used to prevent bookings and cancel existing ones.
- `id` (UUID, Primary Key)
- `doctorId` (String, Foreign Key to Doctor)
- `leaveDate` (Date)
- *Constraint*: Unique combination of `[doctorId, leaveDate]`
- *Timestamps*: `createdAt`

### Appointment
The core model linking patients, doctors, and LLM generated summaries.
- `id` (UUID, Primary Key)
- `patientId` (String, Foreign Key to User)
- `doctorId` (String, Foreign Key to Doctor)
- `startTime` (DateTime)
- `endTime` (DateTime)
- `status` (AppointmentStatus Enum, Default: PENDING)
- `symptomsRaw` (String, Nullable) - Provided by patient during booking.
- `preVisitSummary` (JSON, Nullable) - `{ urgency, complaint, questions }` generated by LLM.
- `postVisitNotesRaw` (String, Nullable) - Provided by doctor after visit.
- `postVisitSummaryPatient` (String, Nullable) - Patient-friendly summary generated by LLM.
- `gcalEventId` (String, Nullable) - ID of the synced Google Calendar event.
- *Timestamps*: `createdAt`, `updatedAt`

### Prescription
Links to an appointment to handle medication scheduling and reminders.
- `id` (UUID, Primary Key)
- `appointmentId` (String, Foreign Key to Appointment)
- `medicationName` (String)
- `frequency` (Frequency Enum)
- `startDate` (Date)
- `endDate` (Date)
- *Timestamps*: `createdAt`
